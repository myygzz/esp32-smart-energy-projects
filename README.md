
# ESP32 Smart Energy Projects

A collection of IoT and smart energy experiments developed while studying Internet of Things Engineering.

## Project 1: Smart Dorm AC Monitor

**Status:** Planning / Development

### Objective

Develop a low-cost IoT device capable of monitoring dormitory room temperature and humidity while providing infrared-based air conditioner control.

### Planned Hardware

- ESP32 development board
- DHT11 temperature and humidity sensor
- OLED display
- IR receiver (VS1838B)
- IR transmitter LED
- Infrared remote control

### Planned Features

- Real-time temperature monitoring
- Humidity monitoring
- Display readings on an OLED screen
- Infrared air conditioner control
- Future possibility of remote monitoring

### Technologies

- C / C++
- Arduino IDE or ESP32 development environment
- ESP32
- IoT
- Embedded Systems

### Development Roadmap

- [ ] Set up ESP32 development environment
- [ ] Read temperature and humidity from DHT11
- [ ] Display sensor data on OLED
- [ ] Receive infrared remote signals
- [ ] Implement AC infrared control
- [ ] Combine all modules
- [ ] Test and document the system

## Project Goal

Explore practical applications of IoT technology in smart living environments and energy management.
